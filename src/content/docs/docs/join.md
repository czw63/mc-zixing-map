## 服务器地址

```
mc.zixing.fun:7030
```

版本 **26.3**，是生电（红石/刷怪塔）向的服务器，不是原版生存。

## 客户端准备

服务器用的是整合包 **26.3生电（based on xplus）**，群文件「玩一辈子MC」里能下载（`.mrpack`，约 156 MB）。

用整合包启动器（Modrinth App / Prism Launcher / HMCL 等）导入 `.mrpack` 就行，别自己拿原版客户端硬连——缺 mod 会直接连不上或者功能不全。

<span class="tbd">待补：整合包具体包含哪些 mod、有没有需要手动开的设置、Java 版本要求。</span>

## 进服之后

<span class="tbd">待补：出生点在哪、第一次进来该去哪领东西、有没有新手引导。</span>

## 连不上怎么办

1. 先确认版本是 26.3，整合包是群文件那个
2. 确认地址带端口 `:7030`，只写 `mc.zixing.fun` 连不上
3. 服务器可能关机或重启中，去群里问一句
