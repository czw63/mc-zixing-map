## 关于在线状态

首页的假人卡片上有个状态点，那是某个时间点检查服务器在线列表的结果，**不代表现在还在挂机**。检查脚本是仓库里的 `scripts/check_bots.py`。

## 注意事项

**别踢假人。** 假人掉线，它挂着的刷怪塔就停了，可能几个小时白挂。

**别把假人拉走、别对它用特定物品。** 有些操作会让假人下线。
