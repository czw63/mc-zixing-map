紫星服务器是一台 **Minecraft 26.3 生电服**（`mc.zixing.fun:7030`）。这里放玩家需要知道的东西：怎么进来、机器在哪、怎么用、什么东西别动。

## 从哪开始

- **第一次进服** → [入服指南](/docs/join/)
- **找机器、查怎么用** → [设施目录](/docs/facilities/)
- **看谁在挂机、假人干什么的** → [假人目录](/docs/bots/)
- **怎么从一个地方走到另一个地方** → [交通](/docs/transport/)
- **什么能做什么不能做** → [服规](/docs/rules/)

## 地图

<https://mc-zixing-map-site.pages.dev> 首页是服务器地图，1 像素 = 1 方块，可以拖拽缩放、搜索地点、点开看坐标。地图数据来自玩家客户端的探索记录，**不是服务器实时状态**——新建的东西要有人走到附近才有。
