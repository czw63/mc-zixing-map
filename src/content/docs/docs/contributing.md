---
title: 怎么改文档
description: 给不写代码的人看的编辑说明
---

改文档不需要懂代码，会写文字就行。改完提交，网站会自己更新。

## 最快的方式

1. 打开仓库 <https://github.com/czw63/mc-zixing-map>
2. 进 `src/content/docs/docs/` 目录，点要改的 `.md` 文件
3. 点右上角铅笔图标，直接在网页上改
4. 下面写一句改了什么，点 **Commit changes**

大概一两分钟后网站就更新了。

## 新建一页

在 `src/content/docs/docs/` 下新建 `.md` 文件，开头必须有这几行：

```markdown
---
title: 页面标题
description: 一句话说明这页讲什么
---

正文从这里开始。
```

新建完去 `astro.config.mjs` 的 `sidebar` 里加一行，不然侧边栏里没有入口。

## 格式速查

| 想写 | 怎么写 |
| --- | --- |
| 大标题 | `## 标题` |
| 小标题 | `### 标题` |
| 加粗 | `**文字**` |
| 代码或指令 | 反引号包起来 |
| 列表 | 每行开头 `- ` |
| 链接 | `[显示文字](/docs/join/)` |
| 提示框 | `:::note` 开头，`:::` 结尾 |

## 写内容的要求

**不知道就写「待补」，不要猜。** 这是这个站唯一的硬规矩。猜错的东西比空着更糟——会有人照着做然后出事。

**坐标用真实数据。** 设施坐标以游戏内路径点为准，不要手打。

**禁忌要写。** 「挂机别站那格」「离开前记得关灯」这种话比「装置正常」有用得多。

## 加设施或假人

这两类是数据，不是文章，改的是 JSON：

- `data/facilities.json` — 设施
- `data/bots.json` — 假人

字段说明在仓库根目录的 `CONTRIBUTING.md`。

## 别做的事

- 别提交截图、日志、调试文件
- 别直接改 `tiles/` 里的地图瓦片，那是脚本生成的
- 别删 `vendor/` 里的许可证文件
