## 基本原则

**别动别人的东西。** 不确定一台机器、一个箱子、一栋建筑是谁的，就当不是你的。

**用完机器要恢复原状。** 开关关回去、漏斗里的东西收走、别把挂机位占着不放。

**大型红石改动先说一声。** 会卡服的装置（大量实体、高频时钟、大规模区块加载）提前在群里讲，别自己上。

**别把服务器地址和坐标往外传。** 尤其是地图上的坐标，公开仓库已经等于公开了，别再往外扩。
